# Handbook

Welcome to **Knowstead** – the central place for documentation, knowledge and collaboration. This handbook is itself written in Knowstead: you can use every page here as an example of macros, templates and structures.

> [!TIP]
> Press <kbd>Ctrl</kbd> + <kbd>K</kbd> at any time to open the command palette and find pages, spaces and commands. Press <kbd>?</kbd> to see all keyboard shortcuts.

<!-- toc -->

## What Knowstead can do

| Area | Features |
| --- | --- |
| **Structure** | Spaces, hierarchical page tree with drag & drop, home pages, personal spaces, journal |
| **Writing** | Rich-text editor with slash menu, outline and clipboard, real-time collaborative editing, Markdown and code pages, tables, diagrams, formulas, macros |
| **Files** | Uploads right in the page, PDF viewer, preview for Office and Visio files, search inside attachments, draw.io diagrams and whiteboard |
| **Planning** | Task planner with columns, timeline and dependencies, assignees, due dates, priorities, checklists, recurring tasks, reminders and calendar subscription, "My tasks" |
| **AI** | Assistant for improving, shortening, translating and summarising texts and for questions about a page (if set up) |
| **Traceability** | Versions with change notes, visual comparison, restore, change log per space, audit log |
| **Quality** | Reviews and multi-stage approval workflows with deputies, mandatory review per space, suggested changes, read confirmations for mandatory documents, review schedule with owners and reminders, content analytics, undoing recent changes |
| **Collaboration** | Comments (also on text passages), mentions, watching, notifications via bell and email, presence indicator |
| **Finding** | Full-text search with filters, tags, properties, backlinks, link map |
| **Permissions** | Global permissions via groups, roles per space, restrictions per page, sign-in via Active Directory, Microsoft Entra ID, SAML and Windows sign-in |
| **Integration** | REST API with tokens, signed webhooks, API connectors for live data, plugins |
| **Operations** | Backups, export as PDF and Word, import from Confluence and other wikis, text recognition for scans, German and English, maintenance, settings – all through the user interface |
