# Keyboard shortcuts

Open the overview at any time with <kbd>?</kbd>.

## General

| Shortcut | Action |
| --- | --- |
| <kbd>Ctrl</kbd> + <kbd>K</kbd> | Command palette (pages, spaces, commands) |
| <kbd>/</kbd> | Open search |
| <kbd>[</kbd> | Show/hide sidebar |
| <kbd>G</kbd> then <kbd>H</kbd> | Home |
| <kbd>G</kbd> then <kbd>S</kbd> | Spaces |
| <kbd>G</kbd> then <kbd>A</kbd> | Activity |
| <kbd>G</kbd> then <kbd>D</kbd> | Drafts |
| <kbd>?</kbd> | Show keyboard shortcuts |

## On a page

| Shortcut | Action |
| --- | --- |
| <kbd>E</kbd> | Edit |
| <kbd>C</kbd> | Create child page |
| <kbd>S</kbd> | Toggle favourite |
| <kbd>H</kbd> | Version history |

## In the editor

| Shortcut | Action |
| --- | --- |
| <kbd>Ctrl</kbd> + <kbd>S</kbd> | Publish |
| <kbd>Esc</kbd> | Close editor (draft is kept) |
| <kbd>/</kbd> | Insert elements and macros |
| <kbd>@</kbd> | Mention a person |
| <kbd>[</kbd><kbd>[</kbd> | Link a page |
| <kbd>Ctrl</kbd> + <kbd>B</kbd> / <kbd>I</kbd> / <kbd>U</kbd> | Bold / italic / underline |
| <kbd>Ctrl</kbd> + <kbd>K</kbd> | Insert link |
| <kbd>Ctrl</kbd> + <kbd>Z</kbd> / <kbd>Y</kbd> | Undo / redo |
| <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>1</kbd>–<kbd>4</kbd> | Heading 1–4 |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>8</kbd> | Bulleted list |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>9</kbd> | Task list |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | Indent/outdent list item |
