# Tastenkürzel

Die Übersicht öffnest du jederzeit mit <kbd>?</kbd>.

## Allgemein

| Kürzel | Aktion |
| --- | --- |
| <kbd>Strg</kbd> + <kbd>K</kbd> | Befehlspalette (Seiten, Bereiche, Befehle) |
| <kbd>/</kbd> | Suche öffnen |
| <kbd>[</kbd> | Seitenleiste ein-/ausblenden |
| <kbd>G</kbd> dann <kbd>H</kbd> | Startseite |
| <kbd>G</kbd> dann <kbd>S</kbd> | Bereiche |
| <kbd>G</kbd> dann <kbd>A</kbd> | Aktivität |
| <kbd>G</kbd> dann <kbd>D</kbd> | Entwürfe |
| <kbd>?</kbd> | Tastenkürzel anzeigen |

## Auf einer Seite

| Kürzel | Aktion |
| --- | --- |
| <kbd>E</kbd> | Bearbeiten |
| <kbd>C</kbd> | Unterseite erstellen |
| <kbd>S</kbd> | Favorit umschalten |
| <kbd>H</kbd> | Versionsgeschichte |

## Im Editor

| Kürzel | Aktion |
| --- | --- |
| <kbd>Strg</kbd> + <kbd>S</kbd> | Veröffentlichen |
| <kbd>Esc</kbd> | Editor schließen (Entwurf bleibt erhalten) |
| <kbd>/</kbd> | Elemente und Makros einfügen |
| <kbd>@</kbd> | Person erwähnen |
| <kbd>[</kbd><kbd>[</kbd> | Seite verlinken |
| <kbd>Strg</kbd> + <kbd>B</kbd> / <kbd>I</kbd> / <kbd>U</kbd> | Fett / Kursiv / Unterstrichen |
| <kbd>Strg</kbd> + <kbd>K</kbd> | Link einfügen |
| <kbd>Strg</kbd> + <kbd>Z</kbd> / <kbd>Y</kbd> | Rückgängig / Wiederholen |
| <kbd>Strg</kbd> + <kbd>Alt</kbd> + <kbd>1</kbd>–<kbd>4</kbd> | Überschrift 1–4 |
| <kbd>Strg</kbd> + <kbd>Umschalt</kbd> + <kbd>8</kbd> | Aufzählung |
| <kbd>Strg</kbd> + <kbd>Umschalt</kbd> + <kbd>9</kbd> | Aufgabenliste |
| <kbd>Tab</kbd> / <kbd>Umschalt</kbd> + <kbd>Tab</kbd> | Listeneintrag ein-/ausrücken |
